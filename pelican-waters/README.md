# Pelican Waters

A calm, elegant theme for Pelican Panel inspired by serene lake waters.

## Features

- **Dual theme support**: Automatically switches between light and dark modes
- **Gloria Hallelujah font**: Fun handwritten typography with good readability
- **Animated decorations**:
  - Animated waves at the bottom of the screen
  - Random water ripples appearing across the page
- **Subtle hover effects**: Gentle card elevation (wave-like rise)
- **Cohesive design**: Glass-morphism effects with backdrop blur

## Installation

1. Copy the `pelican-waters` folder to your Pelican Panel plugins directory
2. Enable the plugin in your panel settings
3. The theme will automatically apply to all panels (admin, server, app)

## Compatibility

- Pelican Panel 1.x
- Supports automatic light/dark mode switching based on system preferences
