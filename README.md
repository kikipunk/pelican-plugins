# Pelican Panel Plugins

More plugins will be added over time.

## Available Plugins

### [minecraft-modrinth](minecraft-modrinth/)

Based on the original version by [Boy132](https://github.com/pelican-dev/plugins/tree/main/minecraft-modrinth).
